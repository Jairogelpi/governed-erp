# Security policy

## Reporting

Please do not disclose suspected vulnerabilities in a public issue. Contact the repository maintainers privately with a concise reproduction, affected component and impact. Do not include credentials, private ERP data or production records.

## Scope

The safety boundary is part of the security model: raw ERP methods are not public capabilities, real write flags are disabled by default, and simulated or fixture behavior must not be treated as production execution.

Supported versions are the current `0.14.x` line and the latest development commit. Security fixes may be backported when practical.
