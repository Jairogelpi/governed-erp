# 00 Current Direction

**Status:** Frozen product direction
**Date:** May 18, 2026

## Decision

Product parent: ERP Agent OS.

The product direction is now fixed for the first buildable phase. The goal is to move from vision to a controlled, testable execution path without expanding into adjacent platform ideas before the MVP is proven.

## Differentiation

1. Any business owner can create ERP automations by talking or by recording the screen.
2. The system converts observed processes into safe reusable skills.
3. Skills execute later with minimal token cost.
4. ERPGuard protects critical actions and blocks unsafe execution.
5. Universal coverage comes from API automation when available and interface automation when not.

## First MVP

Fake ERP Web + Record-to-Skill + Formula Guard Skill + deterministic runtime + audit.

This is the first complete loop the product must prove.

## Guardrails

Do not expand the first buildable phase into SAP, Dynamics, a marketplace, a large UI suite, a browser extension, or a full MCP platform before the MVP loop works end to end.

The current priority is to prove that ERP Agent OS can teach once, convert into a skill, execute cheaply, and leave audit evidence.
